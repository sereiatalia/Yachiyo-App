Privacy Policy

Last updated: August 16, 2026

Yachiyo respects your privacy. This policy explains what information may be collected and how it is used.

Information we may store

  • Discord user, server, channel, and role IDs
  • Server configuration settings
  • Command usage required to operate features
  • Moderation records configured by server administrators
  • Feature data such as introductions, tickets, reaction roles, reminders, and game activity

How information is used

We use this information to provide features, save settings between restarts, respond to interactions, support moderation, and prevent abuse. We do not sell personal information or use stored information for advertising.

Yachiyo may process message content only when required for a configured feature, such as moderation filters, introductions, tickets, or games. Server administrators control which features are enabled.

Data may be stored in a PostgreSQL database hosted by our infrastructure provider and retained only as reasonably necessary to operate the bot. You may request deletion of data connected to your Discord account or server by contacting us.

Yachiyo uses Discord’s API and follows Discord’s Terms of Service and Developer Policy.
